# Blockchain Project

A lightweight, Python-based demonstration of core cryptographic ledger principles built to explore decentralized networks and transaction security.

---

## Features

* **Genesis Block Creation:** Initializes the ledger with a foundational root block.
* **SHA-256 Hashing:** Generates unique cryptographic signatures for every block using Python's `hashlib`.
* **Proof-of-Work (PoW):** Simulates crypto mining with adjustable difficulty targets (`nonce` calculations).
* **Sequential Chain Linking:** Links every block directly to the hash of the preceding block to prevent tampering.

---

## Tech Stack

* **Language:** Python 3
* **Libraries:** `hashlib`, `time`
